Image Toolkit

자주 묻는 질문

Image Toolkit의 파일 처리, 투명 PNG, Canvas Fit, 외곽선, 모바일 사용에 대한 답변입니다.

업로드한 이미지는 서버에 저장되나요?

아니요. 현재 이미지 처리 코드는 브라우저 안에서 실행되며 이미지 파일을 Image Toolkit 서버로 업로드하지 않습니다. GitHub Pages는 정적 파일을 제공할 뿐 이미지 처리 서버를 운영하지 않습니다.

왜 투명 PNG를 권장하나요?

JPG는 투명 배경을 지원하지 않습니다. 외곽선과 알파 bbox 기능을 정확히 사용하려면 투명 PNG가 적합합니다.

Canvas Fit과 단순 리사이즈는 무엇이 다른가요?

단순 리사이즈는 전체 캔버스를 기준으로 줄일 수 있지만, Canvas Fit은 실제 비투명 그림 영역을 감지해 안전 여백 안에서 최대한 크게 배치합니다.

외곽선이 잘리는 이유는 무엇인가요?

원본 그림이 캔버스 가장자리에 붙어 있으면 외곽선이 바깥으로 확장될 공간이 없습니다. 먼저 Canvas Fit을 적용해 여백을 확보하세요.

모바일에서도 사용할 수 있나요?

가능하지만 고해상도 이미지 여러 장은 모바일 메모리를 많이 사용할 수 있습니다. 많은 파일은 데스크톱 브라우저를 권장합니다.

상업적으로 사용할 수 있나요?

도구로 만든 결과물의 권리는 원본 이미지 권리와 별개입니다. 사용자는 자신이 사용할 권한이 있는 이미지만 처리해야 합니다.

이미지 비율이 바뀌나요?

Canvas Fit은 원본 종횡비를 유지합니다. 목표 캔버스와 비율이 다르면 투명 여백이 남으며, 이미지 자체를 가로나 세로로 늘려 찌그러뜨리지 않습니다. 자세한 선택 기준은 비율 가이드에서 확인하세요.

여러 이미지를 한 번에 처리할 수 있나요?

PNG, JPG, JPEG 여러 장을 선택해 같은 Canvas Fit, preset 또는 외곽선 설정을 적용할 수 있습니다. 고해상도 파일이 많으면 브라우저 메모리 사용량이 커질 수 있어 나누어 처리하는 편이 안전합니다.

ZIP 파일에는 어떤 결과가 들어가나요?

처리된 이미지별로 가장 최근에 만든 최종 결과 한 개가 들어갑니다. 같은 파일명이 생기면 덮어쓰지 않도록 번호를 붙입니다. 원본 파일 전체를 보관하는 백업 ZIP은 아닙니다.

결과 이미지가 잘리거나 여백이 커지는 이유는 무엇인가요?

잘림은 그림이나 외곽선이 캔버스 가장자리에 닿을 때 생기고, 큰 여백은 원본의 투명 영역이나 캔버스 비율 차이 때문에 생길 수 있습니다. 문제 해결 가이드에서 증상별 점검 순서를 확인하세요.

설정 초기화는 업로드한 원본도 삭제하나요?

설정 초기화는 캔버스 크기, 외곽선 두께와 색상을 기본값으로 되돌립니다. 업로드 목록을 삭제하는 기능은 아니며, 결과 갱신을 위해 원하는 처리를 다시 적용해야 합니다.
