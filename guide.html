Image Toolkit

사용 방법

PNG 업로드부터 캔버스 맞춤, 외곽선, 탭·대표 이미지, ZIP 다운로드까지 단계별로 설명합니다.

1. 이미지 업로드

PNG, JPG, JPEG 파일을 여러 장 선택합니다.

2. 캔버스 맞춤

기본 규격은 740×640이며 사방 40px의 안전 여백을 남깁니다.

3. 외곽선 적용

두께와 색상을 선택한 뒤 외곽선을 적용합니다.

4. 규격 이미지

  • OGQ 일반 이미지: 740×640, 40px 안전 여백
  • 탭 이미지: 96×74, 4px 안전 여백
  • 대표 이미지: 240×240, 12px 안전 여백

5. 다운로드

각 이미지의 최신 결과를 개별 다운로드하거나 ZIP으로 한 번에 받을 수 있습니다.

원본 이미지는 항상 별도로 보관하세요.

작업 전 준비

가능하면 투명 배경이 보존된 PNG 원본을 준비하고, 원본 폴더는 별도로 복사해 둡니다. JPG도 입력할 수 있지만 투명 배경은 없으며 결과는 PNG로 저장됩니다. 고해상도 파일이 많다면 브라우저 메모리를 고려해 여러 묶음으로 나누세요.

미리보기와 결과 확인

업로드 후 각 카드에서 원본 상태를 확인합니다. 캔버스 맞춤 적용 뒤에는 결과의 픽셀 크기, 실제 그림 크기와 안전 여백을 확인합니다. 외곽선은 외곽선 적용으로 실행하며, 그림이 가장자리에 붙어 있다면 Canvas Fit을 먼저 적용해야 잘림을 줄일 수 있습니다.

작업 후 체크리스트

  • 다운로드한 파일의 너비와 높이가 목표값과 같은지
  • 투명 배경이 유지되는지
  • 외곽선이 네 방향에서 잘리지 않는지
  • ZIP에 이미지별 최신 결과 한 개가 들어 있는지
  • 중복 파일명에 자동 번호가 붙었는지
브라우저를 새로고침하거나 닫으면 작업 상태가 사라질 수 있습니다. 결과를 내려받은 뒤에도 원본을 보관하세요.
