이미지 작업 가이드

여러 이미지를 한 번에 작업할 때 확인해야 할 사항

일괄 처리는 시간을 줄이지만 작은 설정 실수를 모든 파일에 반복할 수 있습니다. 처리 전후 체크리스트가 중요한 이유입니다.

실전 이미지 가이드작성·수정 2026-08-25

처리 전: 원본과 이름을 정리합니다

  • 원본 폴더를 복사해 보관합니다.
  • 서로 다른 이미지가 같은 파일명을 쓰지 않는지 확인합니다.
  • PNG와 JPG가 섞였다면 투명 배경이 필요한 파일을 구분합니다.
  • 가로형·세로형·정사각형을 몇 장씩 표본으로 고릅니다.

설정 전: 공통 기준을 정합니다

최종 너비와 높이뿐 아니라 안전 여백, 외곽선 두께, 배경 투명 여부를 함께 정해야 합니다. 같은 캔버스라도 원본 비율이 다르면 남는 여백은 달라집니다. 모든 그림을 억지로 같은 크기로 보이게 하기보다 시각적 균형을 표본에서 먼저 확인하세요.

처리 후: ZIP만 믿지 말고 표본을 엽니다

  1. 세로형, 가로형, 가장 작은 원본의 결과를 각각 확인합니다.
  2. 픽셀 크기와 파일 확장자를 확인합니다.
  3. 투명 배경과 외곽선 잘림을 어두운·밝은 배경에서 봅니다.
  4. ZIP을 풀어 파일 수와 중복 이름의 자동 번호를 확인합니다.

Image Toolkit의 일괄 처리 방식

여러 PNG/JPG/JPEG를 한 번에 선택할 수 있고 같은 설정을 준비된 이미지 전체에 적용합니다. ZIP에는 이미지별로 가장 최근에 만든 최종 결과 한 개가 들어가며, 같은 이름은 충돌하지 않도록 번호가 붙습니다. 업로드 개수나 용량을 코드에서 고정 제한하지는 않지만 브라우저 메모리 한계가 있으므로 고해상도 파일이 많으면 여러 묶음으로 나누세요.
