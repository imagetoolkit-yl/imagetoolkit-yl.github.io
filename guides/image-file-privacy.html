브라우저 기반 처리란 무엇인가요?

웹 페이지의 JavaScript가 사용자의 기기에서 파일을 읽고 Canvas로 처리한 뒤 결과 Blob을 만드는 방식입니다. 서버 업로드 방식은 파일을 네트워크로 전송하고 원격 서버가 처리 결과를 돌려준다는 점이 다릅니다.

Image Toolkit의 실제 처리 방식

현재 소스에서 이미지 선택은 브라우저 File API를 사용하고, 디코딩은 createImageBitmap 또는 HTMLImageElement, 편집은 Canvas, 다운로드와 ZIP 생성은 브라우저 메모리 안에서 수행합니다. 이미지 파일을 전송하는 fetch, XMLHttpRequest 또는 처리 API 호출은 없습니다. GitHub Pages는 정적 HTML·CSS·JavaScript 파일을 전달하며 이미지 처리 서버를 운영하지 않습니다.

그래도 알아둘 외부 연결

사이트에는 Google AdSense 스크립트가 포함되어 있습니다. 광고 제공 과정에서 Google이 쿠키나 유사 기술을 사용할 수 있으며, 이는 이미지 파일 처리와는 별개의 네트워크 요청입니다. 자세한 사항은 개인정보처리방침에서 확인할 수 있습니다.

사용자가 직접 확인할 항목

  • 주소창의 도메인이 공식 사이트와 일치하는지 확인합니다.
  • 민감한 이미지라면 브라우저 개발자 도구의 Network 탭에서 파일 전송 요청을 확인합니다.
  • 공용 기기에서는 다운로드 파일과 브라우저 기록을 정리합니다.
  • 브라우저를 닫기 전에 결과를 저장하고 원본은 별도로 보관합니다.
현재 구현 기준 설명입니다. 기능이나 외부 서비스가 변경되면 개인정보처리방침과 이 안내도 함께 갱신해야 합니다.
