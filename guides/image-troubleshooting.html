이미지 작업 가이드

이미지 규격 작업에서 자주 발생하는 문제와 해결 방법

결과가 예상과 다를 때는 증상만 고치기보다 원본 비율, 투명 영역, 처리 순서를 차례로 확인해야 합니다.

실전 이미지 가이드작성·수정 2026-08-25

이미지가 찌그러집니다

원인: 너비와 높이를 서로 다른 비율로 강제 변경했습니다. 해결: 비율 유지 Fit을 사용하고 남는 공간은 여백으로 처리합니다.

위아래 또는 좌우가 잘립니다

원인: Crop을 사용했거나 그림과 외곽선이 캔버스 가장자리에 닿았습니다. 해결: Canvas Fit으로 전체 그림을 넣고 외곽선보다 큰 안전 여백을 확보합니다.

예상보다 여백이 큽니다

원인: 원본에 보이지 않는 투명 영역이나 아주 옅은 픽셀이 남아 있을 수 있습니다. 해결: 원본을 체크무늬 배경에서 확인하고 불필요한 픽셀을 정리한 뒤 다시 처리합니다.

투명 배경이 사라집니다

원인: JPG로 저장했거나 투명도를 지원하지 않는 프로그램을 거쳤습니다. 해결: 투명 PNG 원본을 사용하고 결과도 PNG로 저장합니다.

외곽선이 너무 두껍거나 뭉칩니다

원인: 최종 해상도에 비해 두께가 큽니다. 해결: 얇은 값부터 적용하고 눈·입·손가락 같은 작은 공간을 확인합니다.

이미지가 흐려집니다

원인: 작은 원본을 크게 확대했거나 JPG 손실이 누적됐습니다. 해결: 가능한 큰 원본을 사용하고 한 번에 최종 크기로 출력합니다.

파일 용량이 너무 큽니다

원인: 사진을 PNG로 저장하거나 해상도가 필요 이상으로 큽니다. 해결: 투명도가 필요 없는 사진은 별도 도구에서 JPG/WebP를 검토하되 제출 규격을 먼저 확인합니다.

여러 결과의 크기가 다릅니다

원인: 일부 파일에 다른 설정을 적용했거나 최신 결과가 서로 다른 단계입니다. 해결: 설정을 통일해 전체를 다시 처리하고 ZIP 안 각 이미지의 픽셀 크기를 검사합니다.
