네이버 OGQ 심사 규격 이미지 만들기

OGQ 제출용 이미지 3종을 한 번에 준비하세요.

플랫폼 규격 가이드2026-08-05

Image Toolkit에서 바로 만드는 3가지 이미지

  • 740×640 일반 이미지 — 원본명_ogq.png
  • 240×240 대표 이미지 — main.png
  • 96×74 탭 이미지 — tab.png

왜 실제 그림 영역을 기준으로 맞추나요?

투명 캔버스가 아니라 실제 그림을 기준으로 맞춥니다.

권장 작업 순서

  1. PNG 원본을 업로드합니다.
  2. 740×640 일반 이미지 만들기를 누릅니다.
  3. main.png와 tab.png를 각각 만듭니다.
  4. 필요하면 외곽선을 적용합니다.
  5. 크기와 파일명을 최종 확인합니다.

안전 여백 기준

캔버스 크기에 맞는 서로 다른 안전 여백을 사용합니다.

실제 제작 과정에서 해결한 두 가지 오류

1. 외곽선 끝이 캔버스에서 잘리는 문제

40px 안전 여백을 먼저 만든 뒤 외곽선을 적용해 잘림을 방지합니다.

2. 96×74 탭 이미지가 1×2px 점처럼 축소되는 문제

탭 이미지는 4px 여백과 단일 비율 계산으로 점 축소를 방지합니다.

제출 전 체크리스트

  • 일반 이미지가 740×640 PNG인지 확인
  • 대표 이미지가 240×240이고 파일명이 main.png인지 확인
  • 탭 이미지가 96×74이고 파일명이 tab.png인지 확인
  • 투명 배경과 외곽선 잘림 여부 확인
  • OGQ 최신 안내 재확인
