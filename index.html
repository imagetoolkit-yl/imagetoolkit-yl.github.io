도구와 이미지 작업 자료실

반복적인 이미지 규격 작업을 한곳에서

Image Toolkit은 캐릭터, 스티커, 이모티콘, 상품 이미지처럼 최종 캔버스 규격과 투명 여백을 반복해서 맞춰야 하는 사용자를 위한 브라우저 도구입니다. 일반 편집 프로그램에서 파일마다 캔버스를 만들고 위치를 조정하는 과정을 줄이고, 여러 이미지에 같은 기준을 적용한 뒤 결과를 비교하고 내려받을 수 있습니다.

현재 제공하는 기능은 PNG·JPG·JPEG 다중 업로드, alpha bounding box 기준 Canvas Fit, 크기와 안전 여백 preset, 투명 PNG 외곽선, 개별 PNG 및 최신 결과 ZIP 다운로드입니다. Crop이나 WebP 변환처럼 제공하지 않는 기능은 가이드에서도 지원 기능으로 안내하지 않습니다.

기본 작업 흐름

  1. 원본 이미지를 별도로 보관하고 작업할 PNG 또는 JPG를 준비합니다.
  2. 한 장 이상 업로드한 뒤 원본 미리보기를 확인합니다.
  3. 목표 캔버스 크기를 입력하거나 필요한 preset을 선택합니다.
  4. Canvas Fit 결과를 확인하고 필요할 때 외곽선을 적용합니다.
  5. 개별 PNG 또는 ZIP을 내려받아 픽셀 크기와 투명 배경을 최종 확인합니다.

원리를 이해하면 결과를 더 쉽게 고칠 수 있습니다
