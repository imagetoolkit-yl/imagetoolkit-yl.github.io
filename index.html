ImageToolkit 소개

설치 없이 끝내는 일반 이미지 작업

ImageToolkit은 사진, 캐릭터, 스티커와 상품 이미지의 크기 조절, 압축, 형식 변환, 캔버스 맞춤, 외곽선과 일괄 작업을 위한 브라우저 도구 모음입니다. 일반 도구와 플랫폼 규격을 분리해 필요한 작업을 바로 찾을 수 있습니다.

기본 작업 흐름

  1. 원본을 별도로 보관하고 PNG, JPEG 또는 WebP를 준비합니다.
  2. 목적에 맞는 독립 도구나 플랫폼 규격을 엽니다.
  3. 설정을 적용하고 미리보기, 픽셀 크기, 용량과 투명도를 확인합니다.
  4. 개별 결과 또는 여러 이미지 ZIP을 다운로드합니다.

브라우저 파일 처리

이미지 파일은 기기 안에서 처리됩니다

이미지 변환은 현재 탭의 File API, Canvas와 브라우저 메모리에서 실행되며 이미지 파일을 별도 서버로 업로드하지 않습니다.
