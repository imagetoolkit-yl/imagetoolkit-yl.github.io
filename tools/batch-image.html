BATCH IMAGE TOOL

여러 이미지 일괄 처리

여러 파일에 같은 캔버스 크기, 출력 형식과 선택적 외곽선을 적용한 뒤 ZIP으로 받으세요.

일괄 설정

여러 이미지를 놓거나 선택하세요PNG · JPEG · WebP, 최대 30개

파일은 한 장씩 순차 처리되어 브라우저 순간 부하를 줄입니다.

선택 파일과 결과

반복 작업을 한 번에

상품 썸네일, 캐릭터 시안, 게시물 이미지를 같은 규격으로 정리할 때 파일마다 설정을 반복하지 않아도 됩니다. 각 이미지는 비율을 유지한 Fit 방식으로 지정 캔버스 안에 배치됩니다.

처리와 메모리

브라우저는 원본을 해석하고 결과 Blob을 ZIP 다운로드 전까지 메모리에 보관합니다. 이 도구는 최대 30개를 순차 처리하지만 초고해상도 파일이 많으면 탭이 느려질 수 있으므로 여러 묶음으로 나누는 것이 안전합니다.

결과 확인

처리가 끝나면 각 파일의 결과 크기와 용량이 목록에 표시됩니다. 중요한 이미지는 개별 다운로드로 먼저 확인하고, 전체가 적절하면 ZIP을 받으세요. 같은 원본 이름은 폴더에서 충돌할 수 있으므로 업로드 전에 고유한 이름을 권장합니다.
