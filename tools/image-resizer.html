원하는 픽셀 크기로 확대하거나 축소하고, 종횡비를 잠가 이미지가 찌그러지는 것을 막으세요.

원본과 결과

이미지 리사이즈란?

리사이즈는 이미지의 픽셀 수를 바꾸는 작업입니다. 웹 게시물의 표시 크기를 맞추거나 큰 사진의 저장 부담을 줄일 때 유용합니다.

종횡비를 유지해야 하는 이유

종횡비는 너비와 높이의 관계입니다. 잠금 상태에서 한쪽 값만 바꾸면 다른 값이 자동 계산되어 얼굴이나 원형 로고가 늘어나지 않습니다. 확대는 픽셀을 보간할 뿐 원본에 없던 세부 정보를 복원하지 않습니다.

Resize와 Fit/Crop의 차이

Resize는 이미지 자체를 지정 크기로 바꿉니다. Fit은 비율을 지키며 캔버스 안에 전부 보이게 하고, Crop은 캔버스를 채우기 위해 넘치는 부분을 실제로 잘라냅니다.

사용 방법

  1. 이미지를 선택하고 표시된 원본 크기를 확인합니다.
  2. 너비 또는 높이를 입력합니다. 비율 잠금을 풀면 두 값을 독립적으로 정할 수 있습니다.
  3. 결과 크기와 미리보기를 확인한 뒤 다운로드합니다.
