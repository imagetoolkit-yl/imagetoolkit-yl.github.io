온라인 이미지 도구

업로드부터 결과 다운로드까지 브라우저 안에서 처리되는 실제 이미지 작업 도구입니다.

이미지 크기 조절픽셀 너비와 높이를 바꾸고 종횡비를 자동으로 유지합니다.크기 조절하기 →
이미지 압축품질을 조절해 WebP 또는 JPEG 결과 용량을 실제로 비교합니다.압축하기 →
이미지 변환PNG, JPEG, WebP 사이를 변환하고 JPEG 배경색을 선택합니다.형식 변환하기 →
이미지 맞춤 및 자르기전체 이미지를 여백과 함께 맞추거나 초점 위치를 기준으로 실제로 자릅니다.맞춤 및 자르기 →
이미지 외곽선투명 이미지의 알파 경계를 따라 두께와 색상을 적용합니다.외곽선 만들기 →
여러 이미지 일괄 처리최대 30개 이미지에 같은 크기·형식·외곽선 설정을 적용하고 ZIP으로 받습니다.일괄 처리하기 →

이미지 자체는 서버로 전송되지 않습니다. 이미지 변환은 현재 탭의 File API, Canvas와 브라우저 메모리에서 실행됩니다.
